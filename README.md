# Cargo Operations Analytics Platform

## Overview

The Cargo Operations Intelligence Dashboard is an end-to-end data analytics project designed to analyze global cargo shipment operations. The project focuses on freight cost analysis, delivery performance monitoring, and operational efficiency using Python and Power BI.

## Project Objectives

* Analyze shipment operations across multiple countries and vendors.
* Identify major freight cost drivers.
* Evaluate delivery performance and transportation efficiency.
* Develop interactive dashboards for business decision-making.

## Dataset

* 10,324 shipment records
* 43 countries
* 73 vendors
* Shipment value, freight cost, weight, and delivery performance metrics

## Technology Stack

* Python
* Pandas
* NumPy
* Power BI
* Git & GitHub

## Project Workflow

Raw Data → Data Profiling → Data Cleaning → Feature Engineering → KPI Development → Power BI Dashboard

## Key KPIs

* Total Shipments
* Total Shipment Value
* Total Freight Cost
* Countries Served
* Vendor Coverage
* Average Delivery Time
* Cost Per Kilogram

## Dashboard Pages

### Executive Overview

* Shipment KPIs
* Top Countries by Shipment Value
* Shipment Mode Distribution
* Product Group Contribution

### Cost Intelligence

* Top Vendors by Freight Cost
* Freight Cost by Country
* Freight Cost Distribution by Shipment Mode
* Average Cost Per KG by Shipment Mode

### Delivery Performance

* Average Delivery Time
* Delivery Days by Country
* Delivery Days by Vendor
* Delivery Days by Shipment Mode
* Shipment Volume by Mode

## Key Insights

* Freight costs are concentrated among a small number of vendors.
* Nigeria represents the highest freight expenditure.
* Air transportation accounts for the majority of freight spending.
* Air Charter exhibits the highest average cost per kilogram.
* Significant delivery-time variations exist across countries and vendors.
